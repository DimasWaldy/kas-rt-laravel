Prompt khusus untuk akun Gemini kedua:
---
Saya sedang mengerjakan proyek Laravel bernama `kas-rt` untuk aplikasi kas RT. Tujuan utamanya adalah menambahkan fitur iuran bulanan otomatis dengan: 1) admin membuat komponen iuran bulanan, 2) sistem membangkitkan tagihan per warga untuk bulan itu, 3) warga dapat bayar transfer atau offline, dan 4) admin dapat memverifikasi/mengonfirmasi pembayaran.

Yang sudah dibuat:
- Model `IuranBulanan` dan `Tagihan`
- Controller `TagihanController` dengan fungsi `index`, `pay`, `adminIndex`, dan `confirm`
- Controller `IuranBulananController` untuk admin buat/lihat iuran bulanan
- View halaman warga tagihan dan admin verifikasi tagihan
- Route: `/tagihan`, `/tagihan/pay`, `/admin/tagihan`, `/admin/tagihan/confirm`, `/admin/iuran-bulanan`, `/admin/iuran-bulanan/create`
- Sidebar sudah ditambahkan menu Tagihan dan admin billing
- Database migrasi sudah dijalankan, tabel `iuran_bulanans`, `tagihans`, dan kolom `tagihan_id` di `kas_masuks` sudah ada

Flow pembayaran:
1. Admin buat `IuranBulanan` untuk bulan berjalan.
2. Sistem otomatis membuat `Tagihan` untuk semua warga jika ada item iuran bulan ini.
3. Warga buka `/tagihan`, pilih tagihan, lalu bayar dengan `transfer` (upload bukti) atau `offline` (catatan).
4. Sistem menyimpan status `pending_transfer` atau `pending_offline`.
5. Admin buka `/admin/tagihan` dan konfirmasi apakah tagihan sudah `lunas`.

Tolong bantu review kode dan lanjutkan fitur ini dengan prioritas:
- memperbaiki tampilan/tagihan detail jika perlu
- menambahkan breakdown iuran per bulan
- menambahkan notifikasi untuk admin saat ada pembayaran baru
- memperkuat validasi pembayaran transfer/offline
